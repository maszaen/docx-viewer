Halaman ini berfungsi untuk memverifikasi fungsionalitas berkas preview.html secara mandiri. Setiap aksi akan membuka tab baru menggunakan instruksi window.open(..., '_blank', 'noopener') sesuai kebutuhan integrasi sistem utama.

Pengujian Berkas Server (Metode Kueri URL)

Mensimulasikan pemanggilan berkas yang tersimpan di server CodeIgniter 3 via parameter preview.html?file=URL_BERKAS:

No Nama Berkas Format Skenario Verifikasi Aksi
1 sample.docx DOCX Berkas valid (multi-halaman, tabel, format teks, jeda halaman)
2 berkas_tidak_ada.docx HTTP 404 Verifikasi penanganan kesalahan berkas tidak ditemukan di server
3 test_legacy.doc DOC LAMA Verifikasi penolakan otomatis format biner Word 97-2003
